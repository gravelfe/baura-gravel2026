PUBBLICAZIONE
1. Crea un repository pubblico GitHub chiamato, ad esempio, baura-gravel.
2. Carica nella radice del repository tutti i file di questo pacchetto.
3. Apri Settings > Pages.
4. In Build and deployment scegli Deploy from a branch.
5. Seleziona branch main e cartella / (root).
6. Salva.

L'indirizzo sarà simile a:
https://NOMEUTENTE.github.io/baura-gravel/

AGGIORNAMENTO DEL GPX
Per cambiare il percorso senza cambiare il link o il futuro QR Code,
sostituisci il file mantenendo esattamente il nome:
Gravel_Baura_2026.gpx

QR CODE
Il QR definitivo deve essere generato dopo l'attivazione dell'indirizzo GitHub Pages.
Dovrà puntare alla pagina principale, non direttamente al file GPX.
